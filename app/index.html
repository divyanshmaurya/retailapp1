SAP Fiori elements

Requires a SAPUI5 runtime

The same eight scenarios as annotation-driven List Report and Object Page applications, for deployment to SAP BTP where Fiori elements provides variant management, personalisation and the standard SAP interaction model. They bootstrap SAPUI5 from ui5.sap.com; where that is unreachable they explain the failure and link back to the workbench, which shows the same data.

Signing in. The services require an authenticated user. In development CAP uses mocked authentication — sign in as manager / manager, or as analyst or viewer.

Walldorf figures originate from the SAP Customer Checkout “Complete Sales Report” export; the remaining stores are synthesized from the same measured behaviour.
