S.Mart Retail AI

Six AI scenarios over the SAP Customer Checkout data from the S.Mart Walldorf autonomous store, amalgamated with a synthesized six-store network. Built on SAP CAP with OData V4 services, deployable to SAP HANA Cloud.

Same scenarios as SAP Fiori elements — needs a SAPUI5 runtime

Annotation-driven List Report and Object Page apps over the same OData services, for deployment to SAP BTP where Fiori elements provides variant management, personalisation and the standard SAP interaction model. They bootstrap SAPUI5 from ui5.sap.com and render a blank page where that host is unreachable — sap.fe.templates ships only in the closed SAPUI5 distribution, so it cannot be self-hosted. Use the scenario apps above in that case.

Signing in. The services require an authenticated user. In development CAP uses mocked authentication — sign in as manager / manager (or analyst, viewer).

Everything above the Fiori elements section works offline. The command centre, the scenario apps and the API explorer load no external script, font or stylesheet, so they render in an air-gapped landscape. Only the Fiori elements apps need ui5.sap.com.
Walldorf figures originate from the SAP Customer Checkout “Complete Sales Report” export; the rest of the network is synthesized from the same behavioural profile.
