Signing in. The services require an authenticated user. In development CAP uses mocked authentication — sign in as manager / manager (or analyst, viewer).

SAP Fiori elements apps need a SAPUI5 runtime. They bootstrap from https://ui5.sap.com, so they render wherever that host is reachable — SAP Business Application Studio, a local machine, or SAP BTP. In an air-gapped environment use the AI Command Centre, which ships its own rendering and needs no external asset.
Walldorf figures originate from the SAP Customer Checkout “Complete Sales Report” export; the rest of the network is synthesized from the same behavioural profile.
