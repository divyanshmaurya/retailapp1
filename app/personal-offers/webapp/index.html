Personalised Offers could not start

The SAPUI5 runtime could not be loaded.

This is an SAP Fiori elements application. It builds its UI from the OData annotations at runtime, which means it needs the SAPUI5 runtime from ui5.sap.com. That host is not reachable from this machine.

It cannot be bundled into the project: Fiori elements ships as sap.fe.templates in the closed SAPUI5 distribution, and unlike sap.ui.core or sap.m it has no OpenUI5 package on npm.

If the host is reachable, check that the bootstrap URL returns 200 rather than 404 - a pinned SAPUI5 patch version disappears from the CDN once SAP retires it:
curl -I https://ui5.sap.com/resources/sap-ui-core.js

The Scenario Workbench shows the same data, from the same services, with no external dependency. Nothing is lost by using it here.
