Two OData V4 services back everything in this application. This page lists what each one exposes, with live row counts, and lets you run a query and read the response without leaving the browser. The raw $metadata documents are linked at the end of each section — they are XML, so a browser will show them as markup rather than as a page.

    Actions

    The AI service exposes actions as well as entities. These change data, so they are listed rather than wired to a button here — the Scenario Workbench calls the queue actions, and the Command Centre calls recalculate.

    ActionBound toPurpose
    recalculateunboundRe-run one scenario or all of them, optionally scoped to a store
    simulateForecastunboundForecast one article without persisting anything
    simulateMarkdownunboundScore a candidate discount depth against doing nothing
    acknowledgeShrinkAlerts, ColdChainAlerts, AIInsightsMark as picked up, recording a note
    resolveAlertShrinkAlerts, ColdChainAlertsClose with a resolution
    releaseOrderReplenishmentTasksConfirm the proposal and hand it to ordering
    applyMarkdownMarkdownRecommendationsPush the markdown to the shelf labels
    activateNextBestOffersActivate an offer
    dismissFive entitiesClose as not actionable

    Authentication. Both services require an authenticated user. In development CAP uses mocked authentication — sign in as manager / manager, or as analyst or viewer. In production this is XSUAA, with the Viewer, Analyst and StoreManager role collections defined in xs-security.json.
